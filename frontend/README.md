# Investment Research Frontend

Next.js App Router UI for the local AI investment research API.

From the repository root, use:

```powershell
.\start_workbench.bat
```

Frontend-only startup:

```powershell
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` if the FastAPI backend is not running on
`http://127.0.0.1:8000`.
